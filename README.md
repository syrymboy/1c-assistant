# Ассистент 1С

Интеллектуальный ассистент, который позволяет руководителю, финансисту или менеджеру задать вопрос к данным 1С:Предприятие обычным языком и получить ответ в виде текста, таблицы или графика. Языковая модель превращает вопрос в запрос к 1С, который выполняется только на чтение, а пользователь видит, как именно получен ответ.

## Возможности

- Вход через Keycloak и роли `admin`, `analyst`, `manager`
- Чат с потоковым ответом и историей диалогов
- Сменные LLM-провайдеры: заглушка для демо, облачная модель или локальная через LM Studio
- Ограничение тематики: ассистент отвечает только по 1С и управленческому учёту
- Каталог источников 1С, доступных роли, и выбор источников пользователем (демо-каталог)
- Тарифы и тестовая оплата
- Журнал аудита входов

## Как это работает

1. Пользователь входит через Keycloak и получает JWT-токен.
2. Вопрос из чата уходит в backend, который проверяет токен и роль.
3. Выбранный LLM-провайдер формирует ответ с учётом разрешённых источников.
4. Ответ возвращается потоком и отображается в интерфейсе.

В планах: подключение демо-базы 1С через OData, каталог метаданных с векторным поиском, генерация и проверка запросов, таблицы и графики, оценка качества на тестовом наборе вопросов.

## Технологии

| Часть | Стек |
| --- | --- |
| Frontend | React, TypeScript, Vite, nginx |
| Backend | Python, FastAPI, SQLAlchemy, Alembic |
| Авторизация | Keycloak (OIDC, PKCE) |
| Данные | PostgreSQL |
| LLM | LM Studio (локально), облачный API, заглушка |
| Инфраструктура | Docker Compose |

## Запуск

```bash
docker compose up --build
```

Веб-клиент открывается на http://localhost:3000, документация API на http://localhost:8000/docs.

Тестовые пользователи (только для разработки): `admin1`, `analyst1`, `manager1`, пароль совпадает с логином.

## Структура

```
backend/     FastAPI, миграции, LLM-провайдеры
frontend/    React-клиент
keycloak/    настройки realm, ролей и пользователей
```
